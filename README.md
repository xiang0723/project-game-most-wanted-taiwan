# 全臺通緝令　MOST WANTED · TAIWAN

在臺灣地圖上追捕通緝犯的推理追緝遊戲。你是持有警方特約證照的**賞金獵人**，重大通緝犯正在臺灣本島、澎湖、金門、馬祖與各離島之間流竄。蒐集線索、推理他的去向、封鎖他的退路，在他偷渡出境前把人抓回來領賞金！

🎮 **線上試玩：** https://xiang0723.github.io/project-game-most-wanted-taiwan/

> 不用安裝、不用註冊，電腦和手機瀏覽器都能玩。進度存在你自己的瀏覽器裡。

## 遊戲特色

- **真實的臺灣地圖**：45 個地點，橫跨本島、澎湖、金門、馬祖、綠島、蘭嶼、龜山島、小琉球。交通方式和時間依實際距離計算（警車、高鐵、交通船、國內線班機）。
- **推理追緝**：詢問目擊者、調閱監視器、調閱通聯紀錄、聯絡線民。每條線索會在地圖上畫出「包圍網」，符合最多線索的地點會閃紅光。不過假線索也會把網畫歪。
- **會跑、會躲、會騙人的逃犯**：每個逃犯都有犯罪側寫（空中飛人、地頭蛇、山老鼠、夜貓子、老狐狸、驚弓之鳥）。他越警覺，越會放假消息、臨時改路線，甚至提前偷渡。
- **攻堅與追捕**：申請搜索票，在倒數內點出正確的藏身處。最後一站要先比對監視器畫面；攻堅成功後他會破窗逃跑，要聽聲音判斷他往哪跑。
- **緊張時刻**：限時 10 秒的緊急線報、擦身而過、他的眼線、半夜騷擾、新聞快報，還有嫌犯傳來的嗆聲簡訊。
- **懸賞看板與成長**：每輪四張通緝令，依結果升降獵人等級；累積經驗值解鎖 30 項技能；有連勝加成，讓他跑掉的人兩輪後會變成「宿敵」回來。
- **🃏 卡牌收藏**：逮捕的逃犯會變成卡牌。共 24 種輔助效果，分普通、稀有、傳說三種稀有度，掉什麼卡和他的案由、側寫有關。卡牌用一次就消失，同一種效果每個案子只能用一張；不要的卡可以分解成碎片，再合成想要的卡。
- **特殊任務與案件狀況**：追回贓物、已知港口但不知道開船時間、人質救援、抓一個集團；還會遇到颱風、連假人潮、媒體報導、選舉維安等狀況。
- **在地知識**：每個地點都有真實的歷史與在地特色，結案的報紙會附上「你知道嗎？」小知識。

## 怎麼玩

1. 第一次玩建議先跑一次 **🎓 新手教學**（約 5 分鐘），前輩會一步一步帶你抓到第一個逃犯。
2. 在 **懸賞看板** 挑一張通緝令，看清楚通緝海報上的特徵和犯罪側寫。
3. 到了一個地方先 **調查**。每一站能調查的項數有限，要自己取捨。
4. 依照筆記和地圖上的包圍網，推理他下一站去哪，點地圖上的地點 **出發**。
5. 查到「他就在這裡」時，**申請搜索票攻堅**。攻堅成功後還要追上他。
6. 時間、經費、嫌犯的警覺都要顧好。偷渡倒數歸零，他就逃出國了！

遊戲內按右上角的 **？** 可以看完整的辦案守則。

## 技術

- 純前端：HTML + CSS + 原生 JavaScript，**不需要建置工具**。
- 地圖：[Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/) 圖資。
- 角色頭像：程式依種子產生的 SVG（同一個種子永遠是同一個角色）。
- 音效：Web Audio API 即時合成，沒有音效檔。
- 存檔：瀏覽器 `localStorage`。

## 在自己的電腦上執行

下載或 clone 專案後，在專案資料夾開一個本機伺服器（任何靜態伺服器都可以）：

```bash
python -m http.server 8765
```

然後用瀏覽器打開 http://localhost:8765/

## 專案結構

```
index.html          遊戲頁面（HUD、地圖、面板、各種彈窗）
css/
  style.css         基本版面與手機版
  tape.css          開始畫面、懸賞看板（封鎖線風格）
  tape-game.css     辦案畫面、卡牌、彈窗等遊戲內樣式
js/
  data.js           地點、在地知識、犯罪側寫、案件、技能等遊戲資料
  game.js           遊戲主程式（案件、追緝、攻堅、結算、卡牌、教學）
  map.js            Leaflet 地圖與標記
  avatar.js         角色頭像產生器
  icons.js          介面用的自繪 SVG 圖示
  audio.js          合成音效
```
